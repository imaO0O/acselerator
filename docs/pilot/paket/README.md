# Пакет для партнёра перед пилотом

Что отправить партнёру, чтобы его материалы пришли сразу в нужном виде, и как загрузить их в агента.
Собирается командой `python scripts/make_partner_package.py`.

| Файл | Что это |
|---|---|
| `Pamyatka_partneru.docx` | Одна страница для партнёра: что нужно, обезличивание, как передать, что дальше. Перед отправкой впишите контакты в последней строке |
| `Shablon_dannyh_dlya_pilota.xlsx` | Книга для заполнения: «Реестр документов», «Вопросы», «Справочник параметров», «Прайс». Обязательные столбцы — оранжевые, подсказки — в примечаниях к заголовкам, выпадающие списки — там, где значения фиксированы |

## Два набора вопросов

- **Для настройки** — 20–30 вопросов: партнёр присылает их сразу, по ним настраиваем агента.
- **Закрытый приёмочный** — ещё 30–50 вопросов в отдельной копии той же книги и 10–20 запросов клиентов для
  замера времени. Их составляет эксперт отдела и держит у себя до приёмки; команда до прогона их не видит
  (карточка задачи, п. 2; протокол замера — `docs/pilot/zamer_i_stoimost.md`).

## Когда материалы пришли

1. Документы — в `data/raw/partner/`. Excel и изображения загрузите через «Администрирование» → «Документы»:
   сборка индекса читает из папки только PDF и DOCX (загрузчик напомнит).
2. Загрузить книгу:
   ```bat
   python scripts\import_partner.py Шаблон_от_партнёра.xlsx --docs data\raw\partner
   ```
   Реестр → `data/raw/partner/catalog.yaml`, вопросы → `eval/partner.yaml`, справочник и прайс →
   `data/partner_import/` (загрузить на вкладке «Справочник» администрирования — там та же проверка).
   Ошибочные строки не загружаются; их список с листом и строкой Excel — в `…_oshibki.csv` рядом с книгой,
   его можно отправить партнёру на исправление.
3. Индекс и прогон:
   ```bat
   python scripts\build_index.py
   python eval\run_eval.py --questions eval\partner.yaml --out partner
   ```
4. Приёмка — закрытый набор загружается только перед приёмочным прогоном, в отдельный файл, без правок агента
   после него:
   ```bat
   python scripts\import_partner.py Приёмка.xlsx --docs data\raw\partner --questions eval\priemka.yaml --prefix A --only-questions
   python eval\run_eval.py --questions eval\priemka.yaml --out priemka
   ```

**Данные партнёра в git не попадают:** `data/raw/partner/`, `data/partner_import/`, `eval/partner*.yaml`,
`eval/priemka*.yaml`, их результаты в `eval/results/` и файлы ошибок исключены в `.gitignore`. Репозиторий
публичный — проверяйте `git status` перед коммитом.
