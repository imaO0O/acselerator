# ДЕМО: три синтетических торговых примера

Все артикулы, названия, кроссы, цены, остатки, сроки, материал, масса и
применимость вымышлены. Нет реальных брендов, чертежей, каталогов или заявлений
о совместимости с настоящей техникой. «Трактор ДЕМО-Т82», «Автомобиль ДЕМО-А1»
и «Стенд ДЕМО-С1» не обозначают реальные модели. Данные свободны для использования:
оригинальное содержимое набора передано в общественное достояние по CC0 1.0
(https://creativecommons.org/publicdomain/zero/1.0/).

- `agri`: фильтр и втулки для вымышленного трактора.
- `auto`: фильтр и тормозные колодки для вымышленного автомобиля.
- `drawings`: текстовый аннотированный PDF с обозначением, наименованием,
  материалом, массой и спецификацией; без геометрического представления.

Каждая папка содержит `catalog.csv`, `request.csv`, `expected.json`.
Заголовки каталога совпадают с каноническими полями `TradeCatalog.import_table`:
`article,name,brand,group,price,stock,lead_time,vat_rate,cross_refs,applicability`.
Заявки используют распознаваемые `read_file` заголовки «Артикул,Количество».
Точные запросы намеренно содержат визуально совпадающие кириллические буквы
и разные дефисы; эталон требует исходный канонический артикул, а не другую деталь.

Запуск из корня репозитория: `python scripts/eval_trade.py`.
Для сохранения JSON: `python scripts/eval_trade.py --output report.json`.
Работает офлайн, без моделей и OCR; каждый каталог импортируется в новую
временную SQLite БД и обрабатывается через `read_file` и `match_batch`.
Код возврата 0 означает прохождение всех проверок, 1 — ошибку или расхождение.
Набор не меняет рабочие каталоги и не является замером на реальных данных.

Отчет содержит числитель, знаменатель и долю для точных совпадений, покрытия
ожидаемых кросс-кандидатов, покрытия описательных кандидатов, артикула из
текста чертежа и корректного отказа при отсутствии данных. Отсутствующая категория
дает `null`, а не 100%. Покрытие — полнота ожидаемых кандидатов, не точность
всех предложенных кандидатов и не подтверждение применимости. Кроссы заданы
явно в CSV; кросс и описание требуют выбора сотрудника. Проверки импорта,
числа строк, количества, полей чертежа и статуса также влияют на итоговый успех.
Точные позиции спецификации входят в общую точность точных совпадений.

`drawing.pdf` создан заново PyMuPDF из `drawing.txt`. Пересоздание:
`python -c "from kbagent.trade_demo import generate_drawing; generate_drawing()"`.
Поиск опирается на извлеченное текстовое обозначение и спецификацию.
Сходство геометрии не оценивается. Встроенный шрифт Droid Sans Fallback
распространяется по Apache License 2.0 (см. `FONT_LICENSE.txt`);
CC0 относится к содержимому примера, а не к шрифту или библиотекам.
