# Поиск на 100 000 фрагментах

Исходный индекс: 2107 фрагментов, размножен в 48 раз; векторы bge-m3, 1024 числа.

| Этап | Время |
|---|---|
| Построение индекса по словам (BM25) в памяти | 7 с |
| Поиск по словам, медиана на вопрос | 19 мс |
| Поиск по смыслу (точный перебор numpy), медиана | 14 мс |
| Память под векторы | 391 МБ |

Переранжировщик и языковая модель получают одинаковое число кандидатов при любом размере корпуса,
поэтому общее время ответа растёт только на время поиска из таблицы.
